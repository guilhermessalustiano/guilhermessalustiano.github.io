HTML

Hyper Text Markup Language (HTML) é uma linguagem de marcação fundamental para estruturar páginas web, definindo textos, imagens, vídeos, links, cabeçalhos e muitas outras partes de um site.

CSS

Cascade Style Sheets (CSS) é uma linguagem de estilo usada para definir a aparência de uma página web, permitindo controlar cores, layouts, espaçamentos, responsividade, de maneira a tornar o site mais atraente.

Javascript

Javascript (JS) é uma linguagem de programação utilizada para tornar sites mais dinâmicos e interativos. Pode rodar tanto no front-end quanto no back-end (através do NodeJS).

PHP

Hypertext Preprocessor (PHP) é uma linguagem de script executada no server-side que serve para criar sites dinâmicos e interativos. Pode se embutir no HTML, sendo versátil e excelente para realizar conexões com bancos de dados.

JQuery

JQuery é uma biblioteca JS criada para simplificar a interação entre Javascript e HTML, permitindo gerenciar eventos, criar animações e utilizar Ajax com menos código.

Você pode baixar a biblioteca e incluí-la localmente ou utilizar uma CDN e linkar no seu HTML (caso utilizado nesta página).

Bootstrap

Bootstrap é um framework front-end utilizado para desenvolver sites e aplicações web responsivas de forma rápida. É uma biblioteca que engloba componentes pré-fabricados em HTML, CSS e Javascript, como botões, formulários, barras de navegação, modais, dentre outros.

Você pode baixar a biblioteca e incluí-la localmente ou utilizar uma CDN e linkar no seu HTML (caso utilizado nesta página).

MySQL

MySQL é um Sistema de Gerenciamento de Banco de Dados (SGBD) utilizado para armazenar, organizar e recuperar dados. Utilizando a linguagem SQL (Structured Query Language), possui alta performance, confiabilidade e facilidade de uso.

Nginx

Nginx é um servidor web HTTP, proxy reverso, balanceador de carga e cache HTTP. Focado em alto desempenho, é excelente para distribuir conteúdo de forma rápida e com baixo consumo de recursos.

Linux

Linux é um sistema operacional (SO) open-source criado por Linus Torvalds. É amplamente utilizado por sua segurança, flexibilidade e escalabilidade, estando presente em servidores, supercomputadores, computadores pessoais (PCs) e dispositivos Android e Raspberry Pi.

Python

Python é uma linguagem de alto nível que possui sintaxe simples e legível. É extremamente poderosa e versátil, sendo usada em aplicações de Automação, Ciência de Dados, Inteligência Artificial e Desenvolvimento Web (back-end).
